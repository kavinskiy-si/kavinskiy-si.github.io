AutoPoster

A personal content publishing tool designed to simplify the process of publishing short-form video content to supported social media platforms.

About the project

AutoPoster is a personal, non-commercial automation project. It is designed for the developer's own social media accounts and is not intended to provide a public service or sell social media automation services.

Personal use

The application is developed for personal use and manages only accounts authorized by the developer.

Video publishing

The application takes locally prepared video files and associated captions and publishes them to supported platforms.

Official APIs

Where an official API is available, AutoPoster uses the platform's official authentication and API mechanisms.

How AutoPoster works

Content is prepared locally before it is sent to a social media platform.

1

Prepare content

A video file and its corresponding caption are placed into a local publishing queue.

2

Authenticate

The user authorizes the application through the authentication mechanism provided by the respective platform.

3

Publish

AutoPoster sends the selected video and metadata to the authorized social media account.

4

Track the result

The application reports whether the requested publishing operation succeeded or failed.

TikTok integration

AutoPoster uses TikTok's official Content Posting API for TikTok publishing functionality.

OAuth authorization

The TikTok account is connected through TikTok's official OAuth authorization flow.

Content Posting API

The application uses the official TikTok Content Posting API to submit video content for publishing.

User-controlled content

Videos and captions are selected by the user before they are submitted to TikTok.

AutoPoster does not request or store a user's TikTok password. Authentication is performed through TikTok's authorization system.

Data handling

AutoPoster is designed to minimize the amount of information it processes.

Video files

Videos are selected from the local publishing queue and transmitted to the selected platform when the user initiates publishing.

Captions

Captions are stored locally alongside the corresponding video and are sent to the selected platform as part of the publishing request.

Authentication

OAuth credentials and tokens are used only to authenticate authorized API requests.

Privacy Policy

AutoPoster does not sell personal information and does not use connected social media data for advertising.

  • Social media accounts are connected through official authorization mechanisms.
  • AutoPoster does not request social media passwords.
  • User-provided videos and captions are used to perform the requested publishing operation.
  • Authentication tokens are not intentionally shared with unrelated third parties.
  • Users can revoke access to the application through the relevant social media platform.
